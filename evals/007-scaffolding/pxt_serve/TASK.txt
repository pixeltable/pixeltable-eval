Build a Pixeltable-powered REST API that serves a movie review analysis pipeline.

Requirements:
- Create a table 'movies/reviews' with columns: title (string), review_text (string)
- Add computed columns using OpenAI:
  - sentiment: classifies the review as positive/negative/neutral
  - summary: generates a one-sentence summary of the review
- Create a @pxt.query function called 'analyze_review' that takes a title and review_text, inserts the row, waits for computed columns, and returns the analysis
- Configure `pxt serve` in pyproject.toml under [tool.pixeltable.serve]:
  - Set the query route: query = "schema:analyze_review"
- Write a schema.py that defines the table and the query function
- The API should be startable with: `python schema.py && pxt serve pipeline`

Files to create:
- schema.py (table definition + query function)
- pyproject.toml (with [tool.pixeltable.serve] configuration)
